# WebFit Desktop — canal piloto

Este repositório distribui instaladores do canal piloto do WebFit Desktop, assinaturas, checksums e o manifesto de atualização.

Não contém o código-fonte do produto nem dados clínicos. As versões piloto destinam-se a ensaios com dados fictícios; não representam liberação para dados reais.

O aplicativo consulta o manifesto público em `releases/latest/download/latest.json`. A instalação de uma atualização requer confirmação no aplicativo.
